# Flow_conditioner_project
This project focuses on the complete development of a Flow Conditioner (FC) used in water metering systems to improve flow quality before the fluid enters the measuring chamber. The project covers the entire product development cycle, including requirement analysis, concept generation, CAD modeling, CFD validation using ANSYS Fluent, product drawing creation, Design for Manufacturing (DFM), and injection mold design.

The primary purpose of the flow conditioner is to reduce flow disturbances, turbulence, and swirl effects, thereby ensuring a more uniform velocity profile and improving water meter measurement accuracy.
